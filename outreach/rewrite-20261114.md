## 2. What changed in the engine

| Old move | New move |
|---|---|
| Compare paths, report a percentage | Classify each path into an intent family, compare families |
| Lead with a coverage number | Lead with width against focus, then name the thin spots |
| Return the audit to the caller and forget it | Write `GapAudit`, return its id, cite it in the send |
| Treat every unmatched path as a gap | State unmatched paths as a hold, because a family no winner runs is an advantage, not a hole |

The engine now refuses to invent a void. When the winners' families are all present, the strike says so
and prices density instead. That is what keeps the tool's word worth something on the second call.
